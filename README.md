# Diabetes Prediction Using Machine Learning

## Project Overview
This project focuses on predicting the likelihood of diabetes in patients using machine learning techniques. The analysis involves exploratory data analysis (EDA), feature engineering, and building predictive models to classify patients as diabetic or non-diabetic. The aim is to provide insights that could support early diagnosis and preventive measures.

## Dataset
The dataset used in this project is publicly available on Kaggle: [Pima Indians Diabetes Database](https://www.kaggle.com/uciml/pima-indians-diabetes-database).  
It contains 768 records with 8 features including glucose levels, blood pressure, BMI, age, and more.
